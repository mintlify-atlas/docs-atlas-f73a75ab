The `GET /posts/{id}` endpoint retrieves a single post by its unique numeric ID. The response includes the full post record along with the aggregated vote count and the owner's details. A valid JWT Bearer token must be supplied with every request.

## Endpoint

```
GET /posts/{id}
```

**Authentication required** — include a Bearer token in the `Authorization` header.

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique numeric identifier of the post to retrieve.
</ParamField>

## Response

**HTTP 200 OK** — Returns a single `PostOut` object.

<ResponseField name="Post" type="object">
  The full post record.

  <Expandable title="Post fields">
    <ResponseField name="id" type="integer">
      Unique numeric identifier for the post.
    </ResponseField>

    <ResponseField name="title" type="string">
      Title of the post.
    </ResponseField>

    <ResponseField name="content" type="string">
      Body/content of the post.
    </ResponseField>

    <ResponseField name="published" type="boolean">
      Whether the post is published. Defaults to `true`.
    </ResponseField>

    <ResponseField name="created_at" type="string (datetime)">
      ISO 8601 timestamp of when the post was created.
    </ResponseField>

    <ResponseField name="owner" type="object">
      The user who owns the post.

      <Expandable title="Owner fields">
        <ResponseField name="id" type="integer">
          Unique numeric ID of the owner.
        </ResponseField>

        <ResponseField name="email" type="string">
          Email address of the owner.
        </ResponseField>

        <ResponseField name="created_at" type="string (datetime)">
          ISO 8601 timestamp of when the owner account was created.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vote" type="integer">
  Total number of votes this post has received.
</ResponseField>

## Error Responses

| Status Code | Description |
|-------------|-------------|
| `401 Unauthorized` | No token was provided or the token is invalid/expired. |
| `404 Not Found` | No post with the specified `id` exists. |

## Examples

<CodeGroup>

```bash cURL
# Fetch post with ID 1
curl -H "Authorization: Bearer TOKEN" \
  http://localhost:8000/posts/1
```

```python Python
import requests

BASE_URL = "http://localhost:8000"
HEADERS = {"Authorization": "Bearer TOKEN"}

post_id = 1
response = requests.get(f"{BASE_URL}/posts/{post_id}", headers=HEADERS)
print(response.json())
```

</CodeGroup>

### Successful Response Example

```json
{
  "Post": {
    "id": 1,
    "title": "Hello World",
    "content": "This is my first post.",
    "published": true,

    }

```

```json
{
  "detail": "Post with the id:99 was not found"
}
```
